# Data folder

`fcm_demo.rds` and `fcm_demo.csv` are generated automatically by `R/01_generate_demo_data.R` using a fixed seed.

The demonstration corpus is synthetic. It contains no real participants, trial results, citation counts, or funding disclosures.

Do not place licensed Scopus or Web of Science exports here. Store raw exports in `data-raw/`, exclude them from public version control, and retain their licence restrictions.
